# アニメーションカーブの解釈（Maya との違いの調査）

ビューアのアニメーションカーブの評価（`web_src/src/animation.js`）が、Maya とどこまで同じかを調べた結果と、
Maya で確かめる手順をまとめる。

## 調べ方

Maya の評価の計算は公開されていないが、Autodesk が **animX**（https://github.com/Autodesk/animx 、Apache License 2.0）
という「Maya とまったく同じ方法でアニメーションカーブの値を計算する」ライブラリを公開している。animX は Maya と結果を
比べるテストつきで、次を含む。

- 区間の補間: 重みなしのエルミート・重み付きのベジエ（制御点が区間からはみ出すときの直し方を含む）・リニア・ステップ
- 範囲外: 一定・リニア・繰り返し・オフセット付き繰り返し・往復
- オート系の接線の計算: オート・オートミックス・オートイーズ

animX の該当部分を JavaScript に書き写した参照実装（`web_src/tests/animxReference.mjs`）を作り、ビューアの評価と
ランダムなカーブ（約 1,100 本・範囲の外まで細かく）で値を比べた（`web_src/tests/animx.test.mjs`）。

animX に含まれないもの（スプライン・クランプ・プラトーの接線の計算、回転の補間など）は、Maya で評価した値と比べる
しかない。そのための道具（下の「Maya での確認」）を用意した。

## 結果

| 項目 | Maya（animX） | 以前のビューア | 現在 | 確かめ方 |
|---|---|---|---|---|
| 重みなしの区間（エルミート） | 接線の傾きと区間の長さで 3 次式 | 同じ | 同じ | animX と比較 |
| 範囲外（一定・リニア・繰り返し・オフセット付き・往復） | | 同じ | 同じ（※1） | animX と比較 |
| オート（.ma の 18） | 両隣を結ぶ傾きを、両隣の傾きの 3 倍で抑える。山・谷と両端は平ら | 同じ | 同じ | animX と比較 |
| **オートミックス（19）** | 両隣の傾きを、キーの時間の位置で線形に混ぜてから抑える | **オートと同じに計算（違う）** | 直した | animX と比較 |
| **オートイーズ（20）** | 近い側の傾きを強く効かせる 3 次の混ぜ方（係数 −0.5） | **オートと同じに計算（違う）** | 直した | animX と比較 |
| オートカスタム（21） | 係数を Maya の設定で決める | オートと同じ | オートイーズと同じ（※2） | 未確認 |
| **重み付きの区間で、接線が区間の 3 倍より長いとき** | 時刻が逆戻りしない範囲（楕円の内側）まで制御点を詰める。傾きは保つ | **制御点を区間の端で打ち切る（違う）** | 直した | animX と比較 |
| **キーの時刻のごく近く（1e-10 秒以内）** | キーの値 | 区間の式（ステップでは前のキーの値になる） | キーの値 | animX と比較 |
| リニア・フラット・ステップ・ステップ（次）・固定 | | 同じ | 同じ | animX と比較 |
| スプライン（9）・クランプ（10）・プラトー（16） | 計算は非公開（animX にもない） | 近似 | 近似のまま | **Maya での確認が必要** |
| 回転の補間（同期したオイラー・クォータニオン） | rotationInterpolation で X・Y・Z をまとめて補間 | 未対応（X・Y・Z を別々に補間） | 未対応のまま | **Maya での確認が必要**（差の大きさを測る） |
| .ma の接線の種類の番号 19〜21 | | オートミックス・オートイーズ・オートカスタムと想定 | 同じ想定 | **Maya での確認が必要** |
| キーの時刻・値の精度 | 倍精度 | 単精度（float32）で受け渡す | 同じ（※3） | — |

- ※1 Maya は範囲外を折り返すとき時刻を 1/141,120,000 秒の刻み（tick）に丸めるので、値の 100 万分の 1 程度違うことがある（見た目には出ない）。
- ※2 animX のテストも、オートカスタムをオートイーズとして扱っている（係数を読めないため）。
- ※3 有効数字が約 7 桁なので、値が 1,000 程度なら 0.0001 程度まで正確（表示には影響しない）。必要になれば倍精度にできる（共通 JSON の times・values）。

### 影響が出るシーン

- **オートミックス・オートイーズの接線を使うシーン**: キーの間隔が不均等なところで、以前は曲線の形が Maya と違っていた
  （両隣の傾きの 3 倍の頭打ちにかからないとき）。
- **重み付きのカーブで、接線をキーの間隔の 3 倍より長くしたところ**: 以前は立ち上がり・止まり方が Maya と違っていた。

### 近似のまま残っているもの（スプライン・クランプ・プラトー）

ビューアの計算（`prepareCurve` の `computed`）:

- スプライン: 両隣のキーを結ぶ傾き（端のキーは隣のキーへの傾き）
- クランプ: スプライン。ただし隣のキーと値が同じなら平ら（端のキーは隣のキーへの傾き）
- プラトー: 両隣を結ぶ傾きを両隣の傾きの 3 倍で抑え、山・谷と両端は平ら（以前のオートと同じ）

Maya の説明（ヘルプの「接線」）とは合っているが、間隔が不均等なところや端のキーの傾きが Maya と同じかは分からない。
下の手順で Maya と比べれば、差のあるキーと Maya の接線の角度が分かるので、それを元に直せる。

## Maya での確認

1. Maya のスクリプトエディタ（Python）で実行する（パスは書き換える）。

   ```python
   import sys; sys.path.insert(0, r"C:/path/to/MayaSceneViewer/tools")
   import maya_anim_curve_check as m
   m.run(r"C:/temp/curve_check")
   ```

   テスト用のシーンを作って `curve_check.ma` に保存し、Maya が評価した値を `curve_check.json` に書き出す。
   シーンには、接線の種類（スプライン・クランプ・プラトー・オート系・リニア・フラット・ステップ・固定）×
   キーの並び（上り・山と谷・平ら・間隔が不均等・2 キー・値の近いキー）× 重みなし・重み付きのカーブと、
   範囲外を変えたもの、回転の補間を変えた回転が入る。
   手持ちのシーンで確かめるときは、そのシーンを開いて `m.export_current(r"C:/temp/my_scene")` を実行する
   （シーンは変えない。.ma で保存しておく）。

2. ビューアのリポジトリで比べる（Node.js が要る。`web_src` で `npm install` を済ませておく）。

   ```
   python tools/compare_anim_curves.py C:/temp/curve_check/curve_check.ma C:/temp/curve_check/curve_check.json --report curve_report.md
   ```

   報告（Markdown）には次が入る。

   - 接線の種類の名前と、.ma に書かれた番号の対応（ビューアの想定と違えば ★）
   - 接線の値（kix など）が .ma に書かれているキーの数（種類ごと。Maya が計算した接線が残っていれば、それを使えば一致させられる）
   - 接線の種類・重み・範囲外ごとの、値の最大の差（一致しないものは ★）
   - 一致しないカーブのキーごとの、Maya の接線の角度・重みとビューアの傾き
   - 回転の補間ごとの、回転の値の最大の差

   `curve_report.md` と `curve_check.json` を共有してもらえれば、スプライン・クランプ・プラトー・回転の補間を Maya に合わせられる。
