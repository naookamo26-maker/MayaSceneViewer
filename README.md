# Maya シーンビューア（簡易版）

Maya ASCII（.ma）のモデル形状・ジョイント・スキンウェイト・アニメーション・カメラを、Maya なしで確認するためのビューアです。
表示は three.js、ウィンドウは PySide6（QtWebEngine）で作られています。Maya 内でも起動でき、その場合は Maya で開いているシーンをそのまま表示します。

シーンの完全な再現は目的にしていません。アニメーションは、キー（アニメーションカーブ）と、主なコンストレイント・IK（回転プレーン・シングルチェーン・スプライン）・計算ノード・キャラクターセット（Trax のクリップを含む）・HumanIK（コントロールリグの FK・リターゲット・スタンス。近似）で動く移動・回転・スケールと、表示（visibility）・カメラの属性を再生します（Maya と同じ考え方の近似。対応範囲は「対応範囲と制限」）。表示するのはポリゴンメッシュ・ジョイント・NURBS カーブ・カメラで、NURBS サーフェスなどは表示しません。

## できること

- **形状の確認**: ポリゴンメッシュの表示（スムーズ／フラット／ワイヤーのみ）。Maya のハードエッジ（スムーズでない辺）では陰影を切って、角を立てて表示します。ワイヤーはポリゴン本来の辺で表示し、三角形分割の対角線は出ません。
- **ライト**: 標準（カメラに追従する平行光と環境光）と、フラット（ライトの影響なし。Maya のフラットライトと同じく、テクスチャやマテリアルの色をそのまま表示）を切り替えられます。
- **骨の確認**: ジョイントの階層と位置を Maya 風の骨の形で表示します（初期状態では非表示。J キーかツールバーのジョイントのアイコンで切り替え）。ローカル軸（選択中のジョイントのみ、またはすべて）も表示できます。
- **カーブの表示**: NURBS カーブ（コントローラーの形・スプライン IK のカーブなど）を線で表示します。色は Maya の描画のオーバーライド（色番号・RGB）とディスプレイレイヤーの色を使い、指定がなければ明るい灰色です。テンプレート表示は灰色、非表示のシェイプと中間オブジェクトは描きません。カーブをクリックすると、その transform を選択します（テンプレート・リファレンスのカーブは、Maya と同じくクリックでは選びません）。ツールバーのカーブのアイコンで表示を切り替えられます（初期状態では非表示）。アニメーションやコントローラーの移動にはそのままついていき、skinCluster や制御点の接続で形が変わるカーブは、変形した形で表示します。
- **ヒストリのあるカーブ**: Maya はヒストリ（形を作るノード）のあるカーブの形を .ma に保存しません。ビューアは、circle（makeNurbCircle。次数 1・3、sweep 360 度）・フリーズトランスフォームなどの transformGeometry・rebuildCurve（作り直しの種類 uniform と keepControlPoints。Maya の計算は公開されていないため、元の形への最小二乗のあてはめで近似）・reverseCurve（向きの反転）・detachCurve（分割）・subCurve（範囲の切り出し）から形を計算して、表示とスプライン IK に使います。これらは、属性が接続されているもの・入力が変形やワールド空間の形のものはリグとして毎フレーム評価し（コントローラーで動かすスプライン IK のカーブなど）、それ以外は読み込んだときに形を求めます。それ以外の形を作るノード（文字の makeTextCurves、offsetCurve・extendCurve・attachCurve など）のカーブは表示できないため、警告とリグの診断（「ヒストリのあるカーブ」）に、カーブと、いちばん奥で計算できなかった形を作るノードの型を出します。Maya でヒストリを削除して保存すると表示できます。
- **視点の操作**: Maya と同じく Alt を押しながらドラッグします（Alt+左: 回転、Alt+中: 移動、Alt+右・Alt+左中: ズーム、ホイール: ズーム。Shift を足すと横か縦だけ）。Alt なしの左ドラッグは矩形選択です。Linux のウィンドウマネージャーによっては Alt+ドラッグがウィンドウの移動に使われるため、その設定を外してください（Maya と同じ）。
- **選択**: ビューポートのクリックで選ぶものを、ツールバーで「オブジェクト」（既定）と「頂点」から選べます（F8 で切り替え）。オブジェクトの選択では、クリックしたメッシュの transform を選び、そのメッシュを選択の色のワイヤーで強調します。頂点の選択では、いちばん近い頂点のウェイトを表示します。右パネル（プロパティ）は、選んでいるものに関係する欄だけを出します（頂点のウェイトの欄は頂点の選択のときだけ、カメラの欄はカメラを選んだときだけ）。
  - **矩形選択・複数選択**: Alt なしで左ドラッグすると矩形選択です（オブジェクトの選択のとき）。矩形に一部でもかかるメッシュ（頂点・辺・面のどれかが入るもの。手前のメッシュに隠れていても選ぶ）・カーブ・表示中のジョイントとコントローラーを選びます。クリック・矩形選択とも、Maya と同じく Shift で切り替え、Ctrl で外す、Ctrl+Shift で加える。階層では Ctrl+クリックで切り替え、Shift+クリックでリードの行からその行までを選びます。最後に選んだもの（リード）をオレンジ、ほかの選択を淡い色で示します。右パネル［選択］は、見出しに選択数とリード（開くと選んだものの一覧。名前をクリックすると、選択はそのままでリードを変える）を出し、ノードの情報はリードを表示します（Maya の Attribute Editor と同じ）。ポーズ確認の数値欄は Maya のチャンネルボックスと同じく、表示はリードの値で、入力した欄（成分）の値を選んだものすべてに入れます（ほかの成分はそれぞれの値のまま。ロック・制限はノードごとに守る。ノードごとに値が違う欄は斜体）。［このノードを戻す］は［選択を戻す（N 個）］になり、選んだものすべてを 1 操作で戻します。カーブエディタは選んだものすべてのカーブを表示します（左の一覧はノードごとにまとめる）。ハンドル（W・E・R）でリードを動かすと、ほかの選択も同じだけ動きます（ワールドの向きのハンドルならワールドで同じ移動・回転、ローカルならそれぞれの軸で。選んだノードの子孫は親と一緒に動くので重ねて動かしません）。F（選択を表示）と H・Ctrl+H・Shift+H は選択したものすべてに働きます。Maya の中で開いたときは、複数の選択も Maya と同期します（最後がリード。選択の解除も同期します）。
  - **Maya での選択の可否**: Maya のビューポートで選べないもの（テンプレート、描画のオーバーライドやディスプレイレイヤーの表示の種類がテンプレート・リファレンスのもの。祖先の設定も引き継ぐ。ロケーターや自作の DAG ノードは、シェイプ側の設定も見ます）は、クリックしても選びません（階層の一覧からは選べます。選択情報に理由を表示）。ツールバーの鍵のアイコン「選択の制限を無視」をオンにすると、これらもクリックで選べます。描画も Maya と同じで、テンプレートのもの（.template か、表示の種類がテンプレート）は灰色で描きます（メッシュはシェーディングせず灰色のワイヤーだけ。ジョイント・ロケーターなどの目印・カーブ・カメラの形も灰色。選んだときは選択の色）。リファレンスのものは選べないだけで、描画はふだんと同じです。
  - **操作方法**: ［ヘルプ］→［操作方法］（F1）で、キー・マウスの操作とツールバーのボタンを、項目（視点・選択・ポーズ確認・表示・アニメーション・ウェイトとマップ・パネル・メニュー）ごとに表で見られます。ボタンはツールバーと同じアイコンで示し、検索欄で操作を探せます。
- **階層**: 左パネルの階層に、transform・ジョイントと、その下のメッシュを表示します。行をクリックすると選択します（メッシュの行ならそのメッシュ。右パネルの［選択］に、頂点数・スキン・UV・マテリアルとテクスチャの状態を表示）。リファレンスから読み込んだノードは、Maya のアウトライナと同じくアイコンに青い菱形の印を付け、名前空間（`armA:` など）を薄く表示します。操作は Maya のアウトライナーに合わせています: ビューポートで選んでも階層は開かず（閉じた中に選択があれば、その祖先の行を薄く強調）、マウスを階層の上に置いて **F** を押すと、選択の行まで開いてスクロールします。階層の上では **↑ ↓** で前後の行を選び、**← →** で閉じる・開く（閉じていれば親、開いていれば最初の子を選ぶ）。名前で絞り込むと、合う行とその親の行（薄く）を表示します。アイコンはジョイント・transform・ロケーター・カメラ・メッシュ（スキンあり）で分けます。
- **表示・非表示**: 階層の各行の目のアイコン（または H / Ctrl+H / Shift+H）で、ノードごとに表示を切り替えられます。Maya と同じく、ノードを隠すとその下のメッシュとジョイントも隠れます。Maya で非表示のノードは、非表示の状態で読み込みます。
  - **リグで切り替える表示**（.ma から読み込んだとき）: コントローラーの独自の属性（geoVis など）や計算ノード（reverse・condition など）、キーで決まる表示（.v・.lodv・描画のオーバーライドの .ovv）も、アニメーションを読み込むとフレームごとに評価します（メッシュ・カーブ（コントローラーの形）のシェイプの表示と、ディスプレイレイヤーの表示（.v・.e）が接続で決まる場合も対象）。リグのコントローラー（ロケーターなど形のないものと、その親のグループ）も対象で、ロケーター（自作のシェイプも）のシェイプの表示はコントローラーの目印に反映します（ファイルでシェイプが非表示なら目印を出さない。子には影響しない）。ポーズ確認でコントローラーを動かしたとき（移動で IK・FK を切り替えるコントローラーなど）も評価し直します。保存時に非表示だったものも、表示がリグで決まるなら、リグの値で表示します（目のアイコンで変えたものは、その状態のまま）。リグで隠れているノードも、目のアイコンで表示し直せます。
- **シーンのカメラ**: シーンにあるカメラ（起動時からある persp・top・front・side は除く）を、ツールバーの［カメラ］か C キーで選んで、そのカメラから見られます（Shift+C で自由視点に戻す）。焦点距離・フィルムバック・フィルムフィット・フィルムオフセット・クリップ面・平行投影を再現し、レンダーの解像度（defaultResolution）の縦横比で解像度ゲートを表示します（外側を暗くする。左上のタイトルと下端のタイムラインに重ならないように収めます）。カメラが多いときは、［カメラ］のメニューの一覧をスクロールできます。カメラのアニメーション（移動・回転・コンストレイント・焦点距離のキーなど）にもついていきます。カメラの形（視野の四角錐）は、［カメラ］の「シーンのカメラを表示」をオンにすると、自由視点で表示します（初期状態はオフ）。
  - **カメラの情報**: 階層でカメラ（transform）を選ぶと、右パネルの［選択］に、焦点距離・画角（水平 / 垂直）・フィルムバック・フィルムフィット・クリップ面・レンダーの解像度を表示します（レンズスクイーズ・フィルムオフセット・カメラスケールは既定と違うときだけ。平行投影のカメラは幅）。キー・リグで決まる値は、いまのフレームの値です。［このカメラから見る］で、そのカメラから表示します。
  - **カメラのビューを動かす**: 再生していないときは、カメラから見たまま Alt+ドラッグ・ホイールで視点を動かせます（いまのフレームのカメラの位置・向きから。焦点距離・解像度ゲートはカメラのまま）。表示だけで、ファイルには保存しません。フレームを動かすか再生すると、カメラの位置に戻ります。再生中は動かせません。回転（タンブル）を始めると視線まわりの傾き（ロール）はなくなります。
  - **開いたときのカメラ**: 保存したときに Maya のビューで見ていたカメラから表示します（.ma の画面構成の「Current Layout」の最初のビュー。Maya 内では作業中のビュー）。persp など起動時のカメラなら自由視点です。
- **カメラシーケンサ**: シーンにショット（shot）があると、ビューポートの上にカメラシーケンサのパネルを出します（再生ボタンなどの操作の行はトラックの下に置き、ツールバーとも下端のシーンのタイムラインとも離しています。シーケンスの再生ボタンは紫）。トラックごとにショットの並び（ショット名・カメラ・範囲）を表示し、再生ボタン・ショット送り・シーケンスのフレームで確認できます。トラックの上をクリック・ドラッグするとそのフレームへ移動し、ビューポートはそのショットのカメラとシーンのフレームで表示します（「シーケンスで見る」）。トラックは Maya と同じくトラック 1 を一番上に、2、3… を下の段に並べ、重なるショットは上の段（番号の小さいトラック）を使います。ミュートしたショットは使いません。scale・preHold・postHold も反映します。ショットの編集（並べ替え・長さの変更）はできません。シーンのタイムラインを操作したり、自分でカメラを選んだり、A・F で視点を合わせ直したりすると、「シーケンスで見る」はオフになります。シーケンスの再生中は、下端のタイムラインの再生ボタンも停止の表示になり、押す（または Alt+V）とシーケンスの再生を止めます（「シーケンスで見る」はそのまま）。再生中にショット送り・先頭・最後・フレームの入力で移動すると、そこから再生を続けます。ショット送りは、表示するショットが変わるフレームに止まります（上の段のショットに隠れているショットの先頭には止まりません）。ショットのカメラが persp などの起動時のカメラでも、そのカメラを読み込みます。
- **姿勢の基準**: 読み込み直後は**バインドポーズ**で表示します（skinCluster の .pm → dagPose → ジョイントの .bps の優先順で、バインド時の姿勢を復元）。同じジョイントのバインド時の姿勢が skinCluster（dagPose）ごとに違う（バインドポーズが複数ある）ときは、動かす頂点の数の合計が多い側を使い、警告と、選択したノードの情報（「バインドポーズが複数」）に姿勢ごとの skinCluster を出します。ほかの側でバインドしたメッシュは、バインドポーズの表示で元の形からずれます。メッシュの元形状と骨がぴったり重なった状態から確認できます。ツールバーの**バインドポーズのボタン**（T ポーズの人のアイコン。押した状態がバインドポーズ）か B キーで「ファイルの値」（保存時のポーズ）と切り替えられます。キーのあるアニメーションを読み込むと、自動で「ファイルの値」に切り替わります（読み込みのあとで自分でバインドポーズを選んでいた場合はそのまま）。
- **テクスチャ・PBR のマップ**: ベースカラー・ノーマルマップ・ラフネス・メタリック・AO・エミッシブ・不透明度を表示します（TGA・PNG・JPEG など。UDIM にも対応）。ツールバーの［マップ］で、合成（PBR）表示と各マップの単独表示を切り替え、合成に使うマップを個別にオン・オフできます。ラフネスなどは、オンにしたときに初めて読み込みます。面ごとのマテリアルの割り当てにも対応し、アルファで透過（切り抜き・半透明）できます。テクスチャのパスは、書かれたパス → プロジェクトの sourceimages → .ma と同じフォルダ、の順に探します（詳細は「対応範囲と制限」）。メッシュを選ぶと、右パネルの［選択］で、マテリアルごとのテクスチャの読み込み状況を確認できます。
- **スキンウェイトの確認**
  - 選択ジョイントのウェイトをヒートマップで表示します（0 = 青、1 = 赤、ウェイトなし = 暗い灰色）。
  - インフルエンスごとに色分けして、境界の混ざり具合を表示します。
  - 頂点の選択（ツールバーか F8）でメッシュをクリックすると、いちばん近い頂点のウェイト一覧を表示します（合計値・インフルエンス数つき）。
  - 9 つ以上のインフルエンスを持つ頂点、合計が 1 でない頂点、ウェイトのない頂点を数えて警告します。
- **ポーズ確認**: ジョイントやトランスフォームを、ビューポートのハンドル（W: 移動、E: 回転、R: スケール）か、右パネル［選択］のポーズ確認欄（移動・回転・スケールの数値）で動かし、ウェイトによる変形を確かめられます。動かした量はローカル軸が基準で、表示だけに使い、ファイルには保存しません。変更は元に戻す・やり直すことができます（Ctrl+Z / Ctrl+Y）。親ジョイントをスケールしたときは、Maya の segmentScaleCompensate と同じく、子の位置だけが伸びて子自身は拡大されません。Maya と同じく、**ロックした属性**（setAttr -l。移動・回転・スケールの成分ごと）は動かしても値が変わりません（ハンドルは消さず、ロックした成分の軸を Maya と同じく灰色で表示し、つかめないようにします（3 成分ともロックならすべて灰色。平面・中央のハンドルは含む軸がすべてロックのときだけ灰色）。複数選んでいるときは、一緒に動かすノードすべてでロックしている軸だけを灰色にします（1 つでも動かせるノードがあればつかめ、ハンドルを動かした量をそれぞれに伝えて、ロックした成分はノードごとに固定します。リードでロックした軸でも、ほかのノードは動きます）。灰色のハンドルを押すと、ロックされていることをステータスバーに表示し、選択は変えません。移動・スケールのハンドルは、Maya と同じく各軸のプラス側だけに矢印・箱を描きます。3 成分ともロックしたものは入力欄を出さず、パネルにロックしたチャンネルを表示します）。**移動・回転・スケールの制限**（Attribute Editor の Limit Information。minTransLimit など）のあるノードは、制限の外まで動かしても端の値で止まります。動かした分はそのノードの移動・回転・スケールの値として扱うので、その値を読む計算ノード・exprespy・ドリブンキーなども追従します（カスタムアトリビュートを経由するリグも、接続があれば同じく追従します）。**キーのある属性**を動かした分は、フレームを変える（再生・タイムラインの操作）とカーブの値に戻ります（キーのない成分はそのまま。戻したことは Ctrl+Z で取り消せます）。
- **アニメーションのプレビュー**（.ma から読み込んだとき）: ジョイントやトランスフォームの移動・回転・スケールのキーを再生します（キャラクターセットのキーと Trax のクリップも再生します）。ビューポート下端のタイムラインで、再生・停止（Alt+V）、フレームの移動（スライダー・数値）、コマ送り（Alt+, / Alt+.）、キー送り（, / .）ができます。再生範囲は Maya の設定（playbackOptions）を使い、タイムラインで変えられます。スキンの変形も一緒に動き、ポーズ確認で加えた変更はアニメーションの上に重なります。
  - アニメーションは「ファイルの値」の姿勢で再生します（読み込んだときと、タイムラインを操作したときに自動で切り替わります）。バインドポーズのボタン（B）でバインドポーズに戻すと、どのフレームにいても同じ姿勢になります。バインドポーズの情報がないノード（一番上のグループなど）は、保存したときのフレームの値で表示します。
  - **リグ**: コンストレイント（point・orient・parent・scale・poleVector・aim、カメラとエイムの lookAt）、IK（回転プレーン・シングルチェーン・スプライン。ジョイントの数は問わない）、計算ノード・行列ノード・四元数ノード・ドリブンキー・アニメーションレイヤー・expression・exprespy（Python で式を書くプラグイン）などで動くノードも評価します（一覧は「対応範囲と制限」の「リグ」）。プラグインの自作ノードも、同梱の定義（下の「自作ノードの定義」）があれば評価します。コントローラー（ジョイント・メッシュ以外でリグを動かすノードと、ほかのノードの表示などを切り替えるスイッチのうち、カーブの形のないもの。ロケーター・自作のシェイプの属性で切り替えるときはその transform）は、役割ごとの形の目印で表示します（下の「コントローラーの目印」）。表示はジョイントとは別に、L キーかツールバーのコントローラー（菱形）のアイコンで切り替えます（Maya でジョイントとロケーターの表示を別々に切り替えるのと同じ。初期状態では非表示）。ポーズ確認でコントローラーを動かすと、IK やコンストレイントが追従します（例: 手のコントローラーを動かすと腕が曲がる）。キーがなくリグだけのシーンでも、タイムラインは出さずに評価します。
  - **コントローラーの目印**: リグでの使われ方から役割を判定し、形を変えます。1 つのノードが複数の役割を持つときは、この順で先のものを使います。
    | 形 | 役割 | 判定のしかた |
    |---|---|---|
    | 立方体 | IK コントローラー | ikHandle と、その親 |
    | 四角錐（先が肘・膝を指す。破線で結ぶ） | ポールベクター | poleVectorConstraint のターゲット |
    | 球（3 本の輪） | スプライン IK の制御 | スプライン IK のカーブを変形する cluster のハンドルなど、上級ツイストの上方向のノード |
    | 4 方向の矢印 | コンストレイントのターゲット | point・orient・parent・scale コンストレイントのターゲット |
    | 照準（向くノードと破線で結ぶ） | エイム・注視のターゲット | aimConstraint・lookAt のターゲットと上方向のノード |
    | 旗 | 属性のスイッチ | 値が condition・reverse・blendColors などの計算ノードに入る（IK/FK の切り替えなど）か、ほかのノードの表示（.v など）を切り替える（ロケーター・自作のシェイプの属性も） |
    | 四面体 | ドリブンキーのドライバー | animCurveUA・UL・UU・UT の入力（unitConversion を挟んだものも） |
    | 十字 | ロケーター・計算の材料 | ロケーター（プラグインの自作のロケーターなども）、または distanceBetween・decomposeMatrix などに行列を渡すノード |
    | 八面体 | その他 | 上のどれにも当たらない |

    目印はノードのピボット（ロケーターは localPosition）に置きます（フリーズしたコントローラーや cluster のハンドルも、形の位置に出ます）。菱形のアイコンの右の ▾ で開くパネルで、次を設定できます。
    - **種別ごとの表示**: チェックを外した種別を隠します（シーンにある数も表示。ない種別は薄く表示）。
    - **色**: 「役割」（形と同じく役割で塗り分け）か「左右」（左＝青・右＝赤・中央＝黄。名前の L_ / _R・left などから決め、分からなければ X 座標の正負）。どちらも、Maya の描画のオーバーライド・ディスプレイレイヤーの色があればそれを使います。
    - **大きさの基準**: 「近くの骨」（既定。IK ならチェーンの骨、ほかは動かす先のジョイントの骨の長さに合わせる。指のコントローラーは小さく、脚は大きくなる）か「画面上で一定」（ズームしても同じピクセル数）。骨のないシーンでは、スキンのあるメッシュ（なければメッシュ全体）の大きさを基準にします。
    - **大きさ**: 倍率（ジョイントの大きさとは別）。

    ツールバーの［ジョイント・コントローラーを前面に表示］（初期状態でオン）のときは、メッシュに隠れずに常に見えます。オフにすると、メッシュの奥のものは隠れます。
  - **読み込みは 2 段階**です。シーン（メッシュ・骨）を先に表示し、アニメーションはそのあと裏で読み込みます。アニメーションのない .ma や、アニメーションを読まない設定（［設定］→［アニメーションを読み込む］）では、表示までの時間は変わりません。
  - **変換結果のキャッシュ**: 変換した結果を保存しておき、同じ .ma を開き直すときは解析と変換を省きます（20 万頂点のシーンで約 2 秒 → 0.1 秒）。.ma・読み込んだリファレンス・自作ノードの設定ファイル・ビューアのプログラムのどれかが変わったとき、リファレンスやテクスチャを探し直して見つかるファイルが変わったとき（あとから置いたテクスチャなど）は、使わずに読み直します。［設定］→［変換結果のキャッシュ］で、使うかどうかの切り替え・使用量（使用量 / 上限・件数）の確認・上限の変更（128 MB〜2 GB。既定 256 MB）・消去ができます。1 つのシーンの保存は、圧縮して元の .ma のおよそ 1 割です（45 MB の .ma で約 5 MB）。置き場所は Windows では `%LOCALAPPDATA%/MayaSceneViewer/cache`、それ以外は `~/.cache/MayaSceneViewer`（環境変数 `MA_VIEWER_CACHE_DIR` で変更、`MA_VIEWER_NO_CACHE=1` で無効）。合計が上限（環境変数 `MA_VIEWER_CACHE_MB` があればそちら）を超えると、古く使ったものから消します。
  - 補間は Maya に近い近似です（詳細は「対応範囲と制限」）。
- **カーブエディタ**（Maya の Graph Editor の確認用。見るだけで、カーブは変えません）: 画面の下の、左右のパネルもまたぐ全幅のパネル（初期状態では最小化。▴ で開き、上端のドラッグで高さを変える）に、選んだノード（複数可）を動かすアニメーションカーブを、横軸フレーム・縦軸値のグラフで表示します。対象はビューアが読み込んだカーブで、移動・回転・スケールのキー、属性に直接つながるカーブ（表示 .v・ピボットなど）、ドリブンキー（横軸はドライバーの値。一覧に「ドリブンキー」と表示）、計算ノードを通してつながるカーブです。色は Maya と同じく X 赤・Y 緑・Z 青、値の単位はファイルと同じ（回転は度）、前後の無限（pre / post infinity）の部分は点線です。キーをクリックすると、フレーム・値・接線の種類（イン・アウト）・ウェイト付きか・前後の無限の種類を表示し、接線のハンドルを描きます。ホイールでズーム（Shift で横だけ・Ctrl で縦だけ）、ドラッグで移動、右ドラッグでズーム、上端の目盛りのドラッグでフレームを動かし、A で全体・F で選んだキーを表示します（ポインターがパネルの上にあるとき）。左の一覧は Maya と同じくノードごとにまとめ（選んだ順）、ノードの見出しの下にカーブを並べます。見出しの ▾ で折りたたみ、見出しのチェックでそのノードのカーブをまとめて表示・非表示（一部だけ表示なら中間の表示）、見出しのダブルクリックでそのノードのカーブだけを表示します。カーブの行のチェックでそのカーブの表示を切り替え、ダブルクリックでそのカーブだけを表示します。一覧の行にポインターを乗せると、そのカーブ（見出しならそのノードのカーブすべて）を太く、ほかを薄く描きます。キーをクリックすると、一覧のそのカーブの行も強調します（複数のノードのときは、情報にノード名も出す）。一覧とグラフのあいだのドラッグで一覧の幅を変えられます（ダブルクリックで元の幅）。正規化のボタンで、カーブごとに値の範囲を -1〜1 にそろえて表示します。現在のフレームの線は再生中も追従します。
- **再生のフレームレート**: ビューポートの右下（ヘッドアップディスプレイ）に、再生中は実際に表示できたフレーム数（直近 1 秒）とシーンのフレームレートを「再生 23.9 / 24.0 fps」のように 1 行で表示します。描画が間に合わずに目標の 9 割を下回ると赤く表示します（再生は実時間なので、間に合わないフレームは飛ばします）。停止後は「直前の再生 23.9 / 24.0 fps」と平均を表示します。ツールバーの［表示］メニューで表示を切り替えられます。
- **再生キャッシュ**: リグ（コンストレイント・IK・計算ノード）の評価結果をフレームごとに覚え、2 周目以降はコピーだけで表示します。止まっているあいだ（操作のあと約 0.3 秒から）は、範囲の全フレームを先に計算しておくので、1 周目から実時間で再生しやすくなります。この計算は、画面を止めないよう Web Worker（CPU のコアの数に応じて最大 4 つ）で並べて行います（作っている途中なら再生中も続けます。ワーカーを使えない環境では、画面のスレッドの空き時間に作ります）。覚えたフレームはタイムラインの上端に緑の帯で、フレーム数と使っているメモリ（目安。リグで形が変わるカーブの形も含む）はヘッドアップディスプレイの 1 段上に表示します（上限に達すると黄色）。ポーズ確認でノードを動かしたときは、必要な分だけ作り直します: リグが読まないノード（リグを動かさないメッシュなど）を動かしても作り直しません。キーのある値（フレームを変えるとカーブの値に戻る）だけを動かしたときも、再生ではもとの姿勢を使うので作り直しません。再生でも残る値（キーのないコントローラーの移動など）を動かしたときは、その姿勢のキャッシュを、動かしたノードの影響を受けるノード（IK の腕など）だけ計算して作り、ほかのノードはもとのキャッシュから写します。もとの姿勢のキャッシュは捨てずに残すので、元に戻す・すべて戻すと、すぐにそれを使います（姿勢ごとに 6 つまで。上限に達したら古いものから捨てます）。メモリの上限はツールバーの［表示］→「リグの再生キャッシュ」で選べます（オフ・128MB・256MB・512MB（既定）・1GB・2GB。次回の起動でも使います）。上限を下げると、先に覚えたフレームから捨てます。覚える行列は 32 ビットの数です（描画も 32 ビットなので、見た目には出ません）。キーや時間につながらない部分は、読み込み後の最初の計算の結果をフレームをまたいで使い回します（こちらはフレーム数によらず、リグの大きさの分だけです。ポーズ確認で動かしたときは、動かしたノードを読んだ値だけを計算し直します）。
- **リファレンス**（.ma から読み込んだとき）: リファレンス（`file -r`。入れ子も含む）の中身も読み込み、ノードの名前に Maya と同じ名前空間を付けて（`rig:shoulder` など）1 つのシーンとして表示します。親のシーンで加えた変更（リファレンスの編集: 値の変更・親の付け替え・接続の追加と削除・属性の追加）と、リファレンスの中のノードを動かすアニメーションカーブ（プレースホルダー経由の接続）も反映します。Maya でアンロードしていたリファレンスは読み込みません。読み込み中は、全体の進捗（開いたファイルとリファレンスの合計。「リファレンス 3 / 12」のように何件目かも表示）と、いま読んでいるファイルの進捗を 2 段で表示します。右パネルの選択情報に、どのリファレンスのノードかを表示します。［設定］→［リファレンスを読み込む］でオフにできます（次に開くファイルから）。
  - **リファレンスのファイルの探し方**: 書かれたパス（環境変数を展開。相対パスならプロジェクトのルート → 読み込む側の .ma のフォルダ → シーンのフォルダが基準）→ 読み込む側の .ma のフォルダ・シーンのフォルダ・プロジェクトの scenes フォルダ・プロジェクトのルートで、ファイル名（見つからなければ親フォルダ名を 1 つずつ足したもの）。別の PC の絶対パスが書かれていても、同じプロジェクトの中にあれば見つけます。見つからないリファレンスは警告に出します（`python -m ma_viewer info` でも一覧を表示）。
- **Maya 連携**（Maya 内で起動したとき）
  - 現在のシーン全体、または選択範囲だけを読み込めます。読み込みはスタンドアロンで .ma を開いたときと同じで、アニメーション・リグ・カーブ・リファレンス・警告・リグの診断もそのまま使えます（下の「Maya 内で読み込む場合」）。
  - ビューアで選んだノードを Maya でも選択し、Maya の選択にもビューアが追従します。
  - ウィンドウを開かずに、現在のシーンをパッケージ（.msv）に書き出せます（`mv.export(...)`。下の「Maya 内」）。

## 使い方

### スタンドアロン

```
pip install -r requirements.txt
python run_viewer.py                 # 空のウィンドウで起動
python run_viewer.py scene.ma        # ファイルを指定して起動
```

起動後は［ファイル］→［開く］（Ctrl+O）を使うか、.ma・.msv・.json をウィンドウにドロップして開きます。F5 で同じファイルを読み直します。［ファイル］→［新規シーン］（Ctrl+N）で、表示中のシーンを閉じて何も開いていない状態に戻します（読み込み中は、アニメーションの段階なら中止して戻します）。

### Maya 内

**シェルフに登録する（おすすめ）**: `install_maya.py` を Maya のビューポートにドラッグ＆ドロップすると、現在のシェルフにボタンが追加されます。

**スクリプトエディタから起動する**:

```python
import sys
sys.path.append(r"C:/tools/maya_ma_viewer")   # このフォルダの場所
import ma_viewer.maya_launcher as mv
mv.show()                 # 現在のシーンを表示
mv.show("selection")      # 選択したノード以下だけを表示
mv.show(None)             # 空のウィンドウ（.ma を開く用途）
mv.export(r"C:/out/scene.msv")                    # ウィンドウを開かずに、現在のシーンをパッケージ（.msv）に書き出す
mv.export(r"C:/out/sel.msv", selection=True)      # 選択したノード以下だけ（animation=False でアニメーションを除く）
mv.reload_and_show()      # 開発用: コードを読み直してから開く
```

`mv.export` はビューアで開いたときと同じ内容を書き出します（表示の状態は入れません）。テクスチャの設定は `textures="all"`・`max_size=1024`・`quality=90` のように指定でき、省略時はパッケージの書き出しの既定値です（下の「パッケージ」）。戻り値は書き出した結果（パス・大きさ・同梱したテクスチャの数・警告）です。ビューアのウィンドウからは、［ファイル］→［パッケージ（.msv）として書き出し…］で書き出せます。

［Maya］メニューで、読み込みのやり直しと、選択の同期（ビューア→Maya、Maya→ビューア）のオン／オフを切り替えられます。

### コマンドライン

```
python -m ma_viewer info scene.ma              # 内容の概要と警告を表示
python -m ma_viewer pack scene.ma -o out.msv      # パッケージ（.msv）に変換（下の「パッケージ」。.json・.msv からも作れる）
python -m ma_viewer build-html -o viewer.html     # ビューアを 1 ファイルの HTML にまとめる（--embed scene.msv でシーン入り。「ブラウザで見る」）
python -m ma_viewer export scene.ma -o out.json   # 共通 JSON に変換（アニメーションも含む。--no-animation で除く。--pretty で字下げ。.msv から戻すこともできる）
python -m ma_viewer view scene.ma              # ビューアで開く
python -m ma_viewer rig scene.ma               # リグの診断（評価できないノードと、IK の極ベクトルなどの上流）。-o で保存
python -m ma_viewer excerpt scene.ma [ノード名...]   # 指定したノード（省略時は lookAt）とその子孫・接続・1 段上流だけを抜き出す（不具合の報告用）。-o で保存
python -m ma_viewer node-defs                  # 同梱した自作ノードの定義（ma_viewer/node_defs）の一覧と誤り
python -m ma_viewer convert-plugin myPlugin.py -o ma_viewer/node_defs/myPlugin.json   # Python のノードプラグインを定義に変換
```

**パッケージ（.msv）**: 変換した結果を、共通 JSON より小さい 1 ファイルにまとめます。テクスチャも入るので、別の PC やブラウザでも同じ見た目で開けます。Qt 版は［ファイル］→［パッケージ（.msv）として書き出し…］（Ctrl+Shift+E）です。前回の設定のまま、保存先を選ぶだけで書き出します。設定（同梱するテクスチャ・テクスチャの最大サイズと品質・表示の状態）は、Maya のオプションボックスと同じく、項目の右端の ❒（メニューを開いてその項目で → キーでも可）で変えます。オプションの画面の［書き出し］でその設定で書き出し、［設定を保存］で設定だけを保存します。書き出したあと、使った設定をステータスバーに表示します。

- 数値（頂点・ウェイト・アニメーションのキーなど）は、base64 にせずバイナリのまま入れて圧縮します。目安として、共通 JSON の 1/3〜1/10 ほどの大きさになります。
- テクスチャは、既定ではアルベド（ベースカラー）だけを入れます。`--textures all` ですべてのマップ、`--textures none` で入れません。入れなかったマップは表示されません（マテリアルの値で表示します）。
- テクスチャは長い辺 2048 px までの WebP にします（`--max-size`・`--quality 65`。ビューアは表示するときも 2048 px までに縮めるので、見た目は変わりません）。アルファ（切り抜き・透明）も残ります。変換には Pillow を使います。Pillow がない場合や `--keep-textures` を付けた場合は、元のファイルのまま入れます。
- 開くときは、zip をメモリの上で展開します（一時ファイルは作りません）。テクスチャは、表示に必要になったときに展開します。
- **表示の状態も保存します**（Qt 版の書き出しのオプションの「表示の状態を保存する」。既定はオン）。カメラ・表示設定（ワイヤー・ライト・ジョイントなど）・非表示にしたノード・フレームと再生範囲・ビューアで変えたポーズを保存し、開いたときにその見た目で表示します。見やすく整えてから渡せます。アニメーションカーブのあるノードのポーズと、選択は保存しません。開いたあと A で全体表示に戻せます。
- .msv を開いた状態で、さらに .msv に書き出すこともできます（同梱のテクスチャをそのまま移します。入っていないマップは元に戻せません）。
- 共通 JSON が必要なとき（Maya 内で書き出したシーンを調べるときなど）は、`python -m ma_viewer export scene.msv -o scene.json` で戻せます（同梱のテクスチャは JSON では表示されません）。Qt 版のメニューからの JSON の書き出しは、パッケージに置き換えました。
- 形式は `docs/data_format.md` の「パッケージ（.msv）」に書いています。

**リグの診断**: 再生した姿勢が Maya と違うとき（IK のアップベクターが反転するなど）の原因探しに使います。Qt 版は［ウインドウ］→［リグの診断…］です。操作方法のウィンドウと同じく、左に項目の一覧と検索欄、右に選んだ項目を出します（最初は「概要」: 項目ごとの状態と要点。評価できないものを含む項目には ★ を付けます。IK ハンドルのように並ぶ項目は、一覧でハンドルごとに分けて選べます。✓ は緑、★ は赤で示します。［すべてコピー］で全体を文字としてコピーできます）。次の内容を一覧にします。

- ファイルが読み込むプラグイン（requires）と、transform として扱った自作ノード。
- **自作のトランスフォームノード**: 型を知らないノード（プラグインの自作ノード）でも、transform らしい証拠（親や子がある・ワールド行列などの transform にしかない出力（.wm・.pm・.pim など）をつないでいる）があれば、通常の transform として扱って評価します（警告に一覧を出します）。移動・回転・スケールの名前（t・r・rx など）の属性への入力や値だけでは transform としません（計算用の自作ノードにも、入力の名前が r・t のものがあるため）。そうした計算用の自作ノードは「評価できないノード」になるので、同梱の定義（プラグインからの変換）か、設定ファイルの割り当てで評価できます。
- 評価できないノード（未対応の型・自作ノード・解釈できない expression・コードを解析できない exprespy とその理由）と、それを使っているノードの属性。
- IK ハンドルごとの上流のつながり：ハンドルの位置・極ベクトル・ひねり・開始ジョイントの親が、何で決まっているかを示します。行頭の ✓ は評価できる、★ は評価できない（そこから先の値はファイルに保存された値のまま）という意味です。
- 読み込まないカーブ（表示していないノードを動かすもの）: 動かすノードから下流へすべての接続をたどり、表示するノードやリグに届くかを調べます。届く場合は ★ と経路を出します（こちらのたどり方の漏れか、評価できないノードを経由しているため、再生に影響します）。届かないものは ✓ で、再生には影響しません（カメラ・使っていないコントローラーなど）。
- HumanIK: キャラクターごとの部位の割り当て、スケルトンを動かすもの（リターゲットのソースのキャラクター・コントロールリグの FK のコントローラーと IK エフェクターの数・スタンス）、FK のコントローラーから求める部位・コントローラーのない部位・Reach が 0 でない IK エフェクター、リターゲットで求める部位と腰の高さの比・ソースにない部位、スタンスで表示する部位と、評価しない HumanIK で動くノード。ほかのキャラクターのソースになっているキャラクターは、そのキャラクターと、部位のジョイントのうちキーのあるものの数。
- 値を求められないノード（バインドポーズの形で推定・推定できない）と、警告の全文。
- （Qt 版のみ）**保存時のフレームの再現チェック**: .ma に保存されたジョイントの回転は、保存したときに Maya が IK を解いた結果です。保存時のフレームでビューアが解いた IK の結果とこれを比べ、IK ハンドルごとに、ジョイントのずれの角度を「ねじれ（骨の軸まわり）」と「曲がり（骨の向き）」に分けて出します。★ があれば、その IK の解き方が Maya と合っていません（極ベクトル（ワールド）とひねりの値も出します）。比べるのはファイルに書かれた回転です（移動がコンストレイントで決まるジョイントは、表示用にはバインドポーズへ置き換えますが、保存された回転はそのまま使います）。ずれがある IK は、解き方の候補（ひねりの向き：今の向き・逆・使わない、極ベクトルの空間：ハンドルの親・ワールド・開始ジョイントの親、肘の側：極ベクトルの側・反対側、スプライン IK のひねりの配り方）を総当たりで試し、ファイルの値に一番合うものと、それで一致する IK の数を出します。終端がハンドルに届いていない場合（ハンドルを動かすリグの側のずれ）と、肘（膝）の向き（ファイルの姿勢から逆算した、Maya が使った極ベクトル＋ひねりの向きと、こちらの値の差。ずれていれば、極ベクトル・ひねりを決めるノードの評価が Maya と違う）も出します。さらに、開始ジョイントの親がファイルの値からずれていないかと、ずれ始めるノード（ルートから順に比べて最初にずれるノード。別の IK で動くならその名前）を出します。親がずれていれば、その IK ではなく親の側（たとえば背骨のスプライン IK）が原因です。極ベクトル・ハンドルの位置・ひねりが、その IK で回るジョイント（またはその子）に依存している（循環）場合も ★ で示します（Maya は 1 つ前の評価の値で解くため、保存された姿勢と入力の値が食い違います）。極ベクトルのコンストレイントの開始の位置の材料（crp・crt・ps の接続元または値）も出します。キーやコンストレイントで決まる成分はファイルに値がないため、評価した値を使って比べます。

**評価のプロファイラ**: 再生が遅いときに、どこに時間がかかっているかを調べます。Qt 版は［ウインドウ］→［評価のプロファイラ］、ブラウザ版はツールバーの［ウインドウ］→［評価のプロファイラ］で、ビューポートの上にパネルを開きます（見出しをつかんで動かせます）。［● 記録］を押してから再生する（フレームを動かす）と、次の内容を記録します。記録していないあいだは何も測らないので、再生の速さに影響しません。

- **フレームの内訳**: 1 フレームごとの積み上げ棒（再生キャッシュから写す・専用の評価・汎用の経路・カーブの形・接続で決まる値・行列の更新と表示とその他・描画）と、フレームバジェット（シーンのフレームレートでの 1 フレームの時間）の線。棒にマウスを乗せると、そのフレームの内訳を出します。記録したフレーム数（キャッシュあり・なし）、平均・最大の時間、表示できたフレームレートも出します。描画は CPU 側で命令を出す時間で、GPU の処理の時間は含みません。
- **リグの評価の内訳**: キャッシュなしで評価したフレームの平均を、種類ごと（キーで動くノード・parentConstraint で動くノード・IK（ikRPsolver）で動くジョイント・計算ノード（multiplyDivide）で動くノードなど。上流のコンストレイント・計算ノード・IK の計算は、最初に読んだノードの時間に入ります）と、経路ごと（専用の評価・汎用の経路に任せたノードとその理由・汎用の経路だけで評価したときの理由）に、ノードの数・1 フレームの時間・割合で出します。ノードごと（時間の大きい 100 個。名前・種類・時間・割合。同じ名前のノードは、区別できるところまで DAG のパスを付ける）にも出し、行を押すとそのノードを選びます（特定のノードが重いのか、多くのノードに分かれているのかを見分けるとき）。「自作ノード」では、exprespy などの自作ノードごとに、計算そのものの時間と、入力の読み込み（上流の値を求める時間を含む。読み込みの中で計算したほかの自作ノードの分は除く）の時間、1 回の計算で読んだ異なる入力の数（かっこはコードが読んだ回数）を分けて出します（どちらを速くすべきかを見分けるとき）。自作ノードは、1 回の計算の中で同じ入力を 1 回だけ読みます（計算は入力の値を書き換えないので、結果は同じ）。グラフの下には、行列の更新・表示・その他の内訳（行列のコピー・姿勢の組み立て・ワールド行列の計算・ジョイントとコントローラーの表示の更新・その他）と、ドローコールの数・ポリゴン数（三角形）を出します。1 ノードの評価は数 µs で、ブラウザの時計は 0.1 ms 程度に丸められることがあるため、記録したフレームを通して足し合わせた平均です（多く記録するほど正確。合計をリグの評価の時間と並べて出します）。
- **再生キャッシュとワーカー**: シーンの数（スキン付きのメッシュ・リグで形が変わるカーブを含む）、専用の評価の計画（汎用の経路に任せた数と理由）、動くノードの数とキャッシュの 1 フレームの大きさ、覚えたフレームの数、上限（128 MB〜2 GB）ごとに入るフレームの数、ワーカーの数と 1 フレームを作る時間（ワーカーの中・全体）。

［このフレームを確かめる］は、表示が壊れて見えるフレームで押すと、いまのフレームを新しい評価器の汎用の経路（基準）・専用の評価・再生キャッシュ（覚えた値）・いま表示している値と、原因を切り分けるための画面側の評価器（キャッシュを使わない）・ワーカーと同じ作り方（このフレームから／再生範囲の先頭から評価）・実際のワーカー（新しく起動したもの／いま動いているもの。ワーカーの中で自作ノードを関数にできた数・専用の評価を使ったか・評価中の問題も出す）で比べて、違う動くノードを出し、表示中のオブジェクトのワールド行列も親から直接たどった値と比べます（どの高速化の経路が原因かを切り分ける。結果は［テキストでコピー］にも入る）。「再生キャッシュを使わずに測る」は既定でオンで、覚えたフレームは捨てずに、記録中だけ毎フレーム評価し直します（リグの評価の内訳は、キャッシュなしで評価したフレームからしか出ないため）。キャッシュがあるときに実時間で再生できるか・描画などの重さだけを見るときは外します。［テキストでコピー］で結果を文字としてコピーできます。

**自作ノードの定義**（ツールの配布者向け）: 自作ノード（プラグイン）の中の計算は .ma に書かれていないため、そのままでは評価できません。属性と計算を書いた**定義ファイル**を `ma_viewer/node_defs/` に置いてビューアと一緒に配ると、利用者の環境にプラグインや Maya がなくても、その計算を再現できます（exe にも必ず含めます）。数が不定の配列の属性・compound・ベクトル・行列・角度・時間を扱え、計算は Python の書き方の一部（代入・if・for・関数）で書きます。書き方は [docs/node_definitions.md](docs/node_definitions.md)、確認は `python -m ma_viewer node-defs`。
Python で書いたノードプラグイン（API 2.0・1.0）は、`python -m ma_viewer convert-plugin myPlugin.py -o ma_viewer/node_defs/myPlugin.json` で定義に変換できます（コードは実行せずに解析します）。変換できないノード（前回の値を覚える・cmds を使う など）は行番号つきで理由を出し、そのノードは書き出しません（[docs/node_definitions.md](docs/node_definitions.md) の「プラグインからの変換」）。

**自作ノードの割り当て**: 同じ計算をする標準ノードがあれば、設定ファイルで割り当てても評価できます（定義を書くより簡単ですが、標準ノードと同じ計算に限ります）。リグの診断に、評価できない自作ノードの型ごとの雛形（つながっている属性名入り）を出すので（follicle・blendShape など Maya の標準の型には出しません。`requires -nodeType` でプラグインの型と書かれた型と、標準の一覧にない型を自作ノードとみなします）、「as」と属性名の対応を書き換えて保存し、開き直してください。

```json
{
  "myMatrixBlend": {"as": "multMatrix", "attrs": {"inMatrix": "i[0]", "outMatrix": "o"}},
  "myCtrlTransform": {"as": "transform"},
  "myCompXform": {"as": "transform", "segmentScaleCompensate": true},
  "myBone": {"as": "joint"}
}
```

- 置き場所（後のものが優先）: `~/.ma_viewer/nodes.json`、環境変数 `MA_VIEWER_NODES` のパス、.ma と同じフォルダの `ma_viewer_nodes.json`。
- 「as」: ビューアが評価できる型（multMatrix・inverseMatrix・decomposeMatrix・composeMatrix・multiplyDivide・plusMinusAverage・transform・joint など）。型を知らない DAG ノードは、指定がなければ transform として扱います（親のスケールを受け継ぎます）。ただし、親があって子がなく、移動・回転・スケールの値・ロック・接続・チャンネルの設定（-k など）のどれも持たず、名前が …Shape（Maya がシェイプに付ける名前）のもの（プラグインのロケーターなど、コントローラーの形を描く自作のシェイプ）はシェイプとして扱い、その transform を標準のロケーターと同じに扱います（コントローラーの目印は十字、色はシェイプの描画のオーバーライド、階層のアイコン、選択情報に型を表示）。シェイプの独自の属性（IK・FK の切り替えなど）もリグで読みます。
- 「segmentScaleCompensate」: transform・joint として扱うノードで、親のスケールを打ち消すか（ジョイントの segmentScaleCompensate と同じ計算。親のスケールの逆数を、ローカル行列の移動の直前に掛けます。inverseScale の接続がなくても親のスケールを使います）。joint の既定は true、transform の既定は false。親のスケールを受け継がない自作の transform（伸び縮みするジョイントの下に置いても、向きがゆがまないもの）に使います。打ち消さずに扱うと、親のスケールが軸ごとに違うときに行列がゆがみ、そのノードを使うコンストレイントの向きがずれます。
- 「attrs」: 自作ノードの属性名 → 標準ノードの短い属性名。`"i"` のように添字なしで書くと元の添字を引き継ぎ（inMatrix[2] → i[2]）、`"i[0]"` のように添字つきで書くとその属性になります。行列を扱う主な型の属性: multMatrix は入力 `i[k]`・出力 `o`、inverseMatrix は `imat` → `omat`、decomposeMatrix は `imat` → `ot`・`or`・`os`・`oq`、composeMatrix は `it`・`ir`・`is` → `omat`。

出力はテキストなので、そのまま貼り付けて相談できます（ファイル本体を渡さなくても、原因の見当がつきます）。

### exe にする（1 ファイル）

PyInstaller で、Python のない PC でも動く 1 ファイルの実行ファイルを作れます。exe は作った OS 用になるので、Windows 用の exe は Windows 上で作ってください。

```
pip install pyinstaller
python packaging/build_exe.py          # → dist/MayaSceneViewer.exe
```

設定は `packaging/maya_ma_viewer.spec` にあります。ビューアの画面ファイル（`ma_viewer/web` の index.html・style.css・viewer.bundle.js）は Python のコードではないため、spec でデータとして同梱しています。実行時は一時展開フォルダ（`_MEI…`）の `ma_viewer/web` に置かれ、`ma_viewer/resources.py` がそこを見つけます。

**アイコン**: exe とウィンドウ（タイトルバー・タスクバー）のアイコンは `ma_viewer/icon/MayaSceneViewer.ico` です（スキンウェイトのヒートマップの色の立方体に、白いワイヤーフレーム）。元の絵は同じフォルダの SVG で、小さいサイズで線が潰れないよう、48px 以上・24〜32px・16〜20px 用に描き分けています。SVG を直したら `python packaging/make_icon.py` で .ico（16〜256px）を作り直してください。Maya 内で起動したときは、Maya のアイコンを変えません。

**自分で PyInstaller のオプションを指定する場合**は、画面ファイルを必ず同梱してください（区切りは Windows では `;`、それ以外では `:`）。

```
pyinstaller --onefile --windowed --name MayaSceneViewer --add-data "ma_viewer/web;ma_viewer/web" run_viewer.py
```

同梱先が `web` でも見つかるようにしてあります。画面ファイルが見つからない場合は、探した場所と対処法をダイアログで表示します。環境変数 `MA_VIEWER_WEB_DIR` で場所を指定することもできます。

**動作確認**: できた exe に `--selftest` を付けると、ファイルを読み込んで結果を書き出し、自動で終了します。

```
dist\MayaSceneViewer.exe samples\sample_arm.ma --selftest --selftest-out selftest.json
```

`selftest.json` の `"ok"` が `true` なら、画面ファイルの読み込み・シーンの表示・WebGL の初期化まで成功しています（`webDir` に、実際に使った画面ファイルの場所が入ります）。

### ブラウザで見る・人に渡す

`ma_viewer/web/index.html` をブラウザで直接開き、［ファイル］→［ローカルファイルから開く…］かドロップで、パッケージ（.msv）か `export` した JSON を読み込めます。.msv ならテクスチャも表示されます（JSON のテクスチャは、書き出した PC のファイルを参照するため、ブラウザの制限や別の PC では表示されないことがあります）。Chrome・Edge で確認しています。

**1 ファイルの HTML（Teams・Slack などで渡す）**: CSS と JS を中に入れた 1 つの HTML（約 1.4 MB）を作ります。受け取った人はダウンロードしてブラウザで開くだけで使えます（Python も Maya もいりません）。配る物を作るときは、exe と同じく `packaging` のスクリプトを使います（出力は exe と同じ場所: 実行したフォルダの `dist/`）。

```
python packaging/build_html.py                        # → dist/MayaSceneViewer.html（ビューアだけ。開いてから .msv をドロップ）
python packaging/build_html.py --embed scene.msv      # → dist/scene.html（シーンを埋め込む。開くとこのシーンを表示）
python packaging/build_html.py --embed a.msv --embed b.ma   # → dist/a.html・dist/b.html（1 ファイルにつき 1 つ）
```

スクリプトは、ビューアの JS（`ma_viewer/web/viewer.bundle.js`）が `web_src` より古そうなら、Node.js があれば作り直してから HTML を作ります（Node.js がなければ注意を出して、いまの JS のまま作ります）。できた HTML が外のファイルを読んでいないことと、バージョンが入っていることも確かめます。`-o` で出力先を指定できます（`--embed` が 1 つのとき）。同じことは `python -m ma_viewer build-html -o viewer.html`（`--embed scene.msv`）でもできます（こちらは JS の確認をせず、指定した場所に作ります）。

`--embed` は .msv をそのまま埋め込むので、テクスチャ・表示の状態（カメラ・表示設定など）も入ります（大きさは約 1.4 MB ＋ .msv の約 1.34 倍）。.ma・.json を指定したら、先にパッケージにしてから入れます（`--textures` で同梱するテクスチャを選べます。既定はアルベドのみ）。会社の設定によっては、HTML の添付が止められたり、開くときに警告が出たりすることがあります。

**URL から開く**: ［ファイル］→［URL から開く…］か、クエリの `file=` で、Web 上の .msv・JSON を開けます。読めるのは、HTML と同じサーバーに置いたファイルと、ほかのページからの読み込みを許可しているサーバー（CORS）のファイルです。Teams・SharePoint・Slack・Google ドライブなど、ログインが必要な場所のファイルや、この PC 上のファイル（file://）は、ブラウザの制限で読めません（ダウンロードしてドロップしてください）。読めないときは、理由（見つからない・ログインが必要・CORS など）を表示します。

**クエリパラメーター**: URL の後ろに付けて、開いたときの見え方を指定できます（.msv に保存した表示の状態より優先。最初に開いたシーンにだけ入れます）。

| パラメーター | 内容 |
|---|---|
| `file=URL` | 開くファイル（.msv・共通 JSON。相対パスなら HTML からの位置） |
| `frame=24` | フレーム |
| `camera=shotCam` | シーンのカメラから見る（transform・カメラの名前かパス） |
| `view=px,py,pz,tx,ty,tz,fov` | 自由視点の位置・注視点・画角（画角は省略可） |
| `wire=1`・`joints=1`・`curves=1`・`grid=0`・`lighting=flat`・`shading=smooth` など | 表示の設定（.msv の表示の状態と同じ項目。オン・オフは 1 / 0、複数の値は `,` 区切り） |

例: `viewer.html?file=scene.msv&frame=24&wire=1&lighting=flat`

**URL をコピー**: ［ファイル］→［URL をコピー］で、いまのカメラ・フレーム・表示の設定（と、URL から開いたならそのファイル）を入れた URL をコピーします。Web サーバーに置いた HTML なら、そのまま人に渡せます。ローカルで開いた HTML の場合は、この PC 上の場所を指す URL になるので、`?` 以降を相手の HTML の URL に付けて使ってもらいます。Qt 版にはありません。

メニューは「開く → 選ぶ」の 2 クリックで設定を変えられます（選択肢をボタンで並べています）。［カメラ］と［ウェイト］は選ぶとメニューを閉じます。メニュー名の横には、既定と違う設定（例: 「マップ ラフネス」）を表示します。メニューは、外をクリックするか Esc で閉じます。

警告は、ログと同じ下部のパネルに表示し、［ログ］［警告］のタブで切り替えます。警告は分類（ファイル・リファレンス・単位／メッシュ・形状／マテリアル・テクスチャ・UV／スキン・デフォーマ／カーブ／アニメーション・リグ／その他）ごとに、見出し（件数）・仕切り線・空行で分けて並べます（表示が Maya と違う・一部を表示できないものだけ。「exprespy を解析した」「同梱の定義で評価した」などのお知らせは警告に入れず、ログに出します）。［ウインドウ］→［警告］で表示・非表示を切り替え、［すべてコピー］で分類ごとの文字としてコピーできます。

ログには、シーンを開くたびに読み込みの経過（開始からの秒数と、段階ごとにかかった秒数: 解析・変換、アニメーションの解析、ビューアでの組み立てと最初の描画、アニメーションの準備）を表にして出し、最後に「シーンを開くのに ◯ 秒かかりました。」を出します（ステータスバーにも出します）。再生キャッシュを作り終えたときも、その時間を出します。シーンの数（メッシュ・頂点・三角形・ジョイント・カメラ）もログに出します。警告はログに 1 件ずつ流さず、件数だけを出します。Qt 版では、画面の最下部はウィンドウのステータスバー 1 列だけです（操作のメッセージを出します）。警告があるときだけ、ツールバーの右側に件数付きの警告アイコンが出て、押すと警告のタブが前面に出ます。

ウェイトを確認するときは、ツールバーの［ウェイト］を「選択ジョイントのヒートマップ」にしてから、ジョイントを選びます（画面上でクリックするか、左の階層でクリック）。頂点ごとの値は、頂点の選択（F8）に切り替えてメッシュをクリックすると、右パネルの［頂点のウェイト］に出ます。

カメラ操作に慣性はなく、マウスを離した時点で止まります。

地面のグリッドの原点を通る線は、X 軸を赤、Z 軸を青で表示します。

ハンドルの向きは、ツールバーの地球のアイコンで切り替えられます（オンでワールド、オフでローカル。スケールは常にローカル）。ワイヤーの重ね表示は、ツールバーのワイヤーのアイコンで切り替えます。

## 対応範囲と制限

読み込める内容（メッシュ・スキン・マテリアル・アニメーション・リグの各ノード）と制限は [docs/support_and_limits.md](docs/support_and_limits.md) にまとめています。主な制限:

- 作業単位は cm だけに対応しています（cm 以外は警告を出します）。
- Maya バイナリ（.mb）は読み込めません。
- リグは、対応しているコンストレイント・IK・計算ノードで評価します。未対応のノードの先は、バインドポーズで推定するかファイルの値のまま表示します（警告とリグの診断に出ます）。

## トラブルシューティング

- **「WebGL を初期化できませんでした」と表示される**: GPU ドライバを更新してください。スタンドアロン版は起動時に `--ignore-gpu-blocklist` を指定しています。環境変数 `QTWEBENGINE_CHROMIUM_FLAGS` を自分で設定している場合は、そちらが優先されます。
- **Maya で「QtWebEngine が含まれていません」と出る**: Maya のスクリプトエディタで `from PySide6 import QtWebEngineWidgets` を実行して確認してください。使えない場合は、`python -m ma_viewer export` で JSON に変換し、スタンドアロン版またはブラウザで開いてください。
- **メッシュが表示されない**: ログの警告を確認してください。多くの場合、ヒストリが残っていて形状データがファイルにありません。
- **スキン変形の表示が Maya と違う気がする**: F12 で開発者ツールを開き、コンソールで `window.mayaViewer.debug.checkSkinning(0)`（0 はメッシュの番号）を実行してください。GPU の変形と、Maya の式による計算を描画結果で比べ、不一致の画素の割合（`ratio`）を返します。0 に近ければ、ビューア内の計算は一致しています。その場合の違いは、データ（ウェイトやバインド行列）か、反映していないデフォーマによるものです。
- **ジョイントが小さすぎる／大きすぎる**: ツールバーの［表示］メニューのスライダーで大きさを変えられます。基準の大きさは、骨の長さの中央値から決めています。
